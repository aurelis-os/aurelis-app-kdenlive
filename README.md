## Description

**kdenlive** is a free and open-source video editor based on the MLT Framework. It supports a wide range of audio and video formats, multi-track editing, transitions, effects, and proxy editing for high-resolution footage. Designed for both beginners and professionals, it provides a flexible interface with customizable layouts and keyboard shortcuts.

## About This Package

This is an **Aurelis Linux** package built as an AppImage. It bundles all dependencies, making it independent of the host system's libraries. While designed for Aurelis Linux, this AppImage can also run as a regular AppImage on **any Linux distribution** (including older distros and musl-based ones like Alpine Linux).
